# Helloword — mi taller de videos

Es mi primer repositorio, denme chance 🙂

Aquí guardo todo lo necesario para hacer y recrear mis videos animados de finanzas:

| Carpeta | Qué hay |
|---|---|
| `kit/` | Código de los videos (Remotion, voces Kokoro, música y efectos). Empieza por `kit/LEEME.md`. |
| `capturas/` | Una hoja de capturas por video. Se ven en mi Biblioteca de Notion. |
| `guiones/` | Guiones de productos, de videos ya hechos y de series por producir. |
| `datos/` | Catálogo de productos Actinver con sus fichas. |
| `CLAUDE.md` | Instrucciones que Claude lee solo al abrir el repositorio. |

## Cómo arrancar un chat nuevo con todo esto
En claude.ai/code (o la pestaña Code de la app), elige el repositorio **neomax4000/Helloword** y escribe, por ejemplo:
> «Haz el video de ACTIREN de la serie de deuda en pesos.»
